# سامانه محاسبات الگوی مولر

نسخه ۱٫۰ — MVP

سامانه‌ای حرفه‌ای برای محاسبه الگوهای خیاطی بر اساس سیستم مولر، با رابط کاربری کاملاً فارسی و راست‌چین.

## ویژگی‌ها

- انتخاب و محاسبه سه الگو (X، Y، Z)
- مدیریت مشتری‌ها (افزودن، ویرایش، حذف)
- ذخیره محاسبات به نام مشتری
- استفاده مجدد از اندازه‌های ذخیره‌شده مشتری
- پشتیبانی از سانتی‌متر و اینچ
- حالت روشن و تاریک
- خروجی PDF فارسی
- فونت وزیرمتن
- طراحی واکنش‌گرا (موبایل، تبلت، دسکتاپ)

## نصب و اجرا

### پیش‌نیاز
- Python 3.10 یا بالاتر

### مراحل

```bash
python -m venv venv

# ویندوز:
venv\Scripts\activate

# لینوکس/مک:
source venv/bin/activate

pip install -r requirements.txt
python run.py
